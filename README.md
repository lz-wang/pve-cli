# pve

A small Proxmox VE CLI for a personal HomeLab, with a single binary and
resource-oriented VM/QEMU and LXC commands. The v3 Go module is
`github.com/lz-wang/pve-cli/v3`; API access uses
[go-proxmox](https://github.com/luthermonson/go-proxmox).

## Install and configure

```bash
brew install lz-wang/tap/pve
pve config add
pve doctor
```

The setup wizard supports hidden token input stored in a separate private
credential file, or an environment-variable reference. Profiles live in
`~/.config/pve/config.yaml`. Token values never appear in `config show` or
doctor output. See the [complete usage guide](docs/usage.md) for configuration,
creation, disks, snapshots, backups and scripting.

Build from source with Go 1.26 or newer:

```bash
make build
bin/pve version
```

## Daily operations

```bash
pve node ls
pve guest ls
pve guest get 100
pve vm ls --name debian --sort name
pve vm get debian-test
pve vm start 100 --wait
pve vm shutdown 100 --wait
pve vm reboot 100 --wait
pve vm stop 100 --wait
pve lxc start 200 --wait
pve lxc shutdown 200 --wait
pve status
pve check --cpu-warn 85 --memory-warn 90
```

Lists, details and operation results support JSON/YAML on stdout; task IDs and
progress use stderr. Exact names are accepted where documented. `guest` also
supports bounded bulk lifecycle operations with previews and confirmation.

This tool covers daily deployments and maintenance. It does not provide a Web
UI, daemon, multi-user control plane, arbitrary REST passthrough, scheduled
backup policy management, or full HA/Ceph/SDN administration. Storage, network
and firewall inventory remains read-only.
